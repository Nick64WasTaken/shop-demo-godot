# Shop Demo
A shop demo created for Godot 4.6

I recently (roughly) finished creating a small demo for Godot 4 in order to demonstrate my skills of game development, asset creation in 3D and 2D, and primarily, game and general programming skills via C#.

To demonstate these skills, I created this demo of a fake in-game shop. While it's not connected to any real game functionality, a proper system that could be integrated into a game with scalability was implemented.
